# Origins and attribution

This development branch adapts David Molik’s tenure portfolio into a Libraries
LaTeX template. The example narratives and bibliographic records retain their
original authorship; individual publications should be cited through their own
records. The working project name is “LaTeX Library Tenure Template.”

The original packet used Xavier Danaux’s ModernCV template, obtained through
LaTeXTemplates.com. The former root-file notice identified version 1.1
(9/12/12), Xavier Danaux (xdanaux@gmail.com), and CC BY-NC-SA 3.0
(<https://creativecommons.org/licenses/by-nc-sa/3.0/>). That provenance is retained
here for adapted source material. The new layout uses the standard article class
and Libraries macros rather than the bundled ModernCV class and themes.

The removed vendored files retain their original notices in the personal
repository’s history. Standard TeX packages used at build time have their own
licenses. Removing old branding does not remove attribution obligations for
retained or derived material.
